# LAST POST 0.3 — 플레이 가능한 개발 버전

## 포함된 개선

- 여섯 장면의 검정 배경 프롤로그와 수동 장면 이동·일시 정지·다시 보기.
- 메시지 질문과 후속 문장 별도 기록, 대화 자료 링크, 자동 저장.
- 현재 단서 기반 조사 안내 및 메시지 진술을 이용한 대체 증거 경로.
- 잠시 표시된 뒤 사라지는 챕터 자막. 프롤로그 재생 중에는 진행하지 않음.
- Notes 증거 편집과 최종 제출, 엔딩 및 후일담.
- 이전 LAST SEEN을 last-seen.html로 보존.

## 배포 전 확인 명령

개발 서버 실행 상태에서 `npm test`, `npm run build`, `npx playwright test`.
빌드는 TypeScript 검사와 Vite 번들 생성을 포함한다. 브라우저 테스트는 Edge를 사용한다.

## 범위

PC 브라우저용 게임이다. 모바일에는 지원 안내를 표시한다. 검색·SNS·메일은 모두 가상이며 외부 메시지를 보내지 않는다. 현재는 텍스트 나레이션이며 성우 녹음이나 장편 상용 출시 수준의 분량을 보장하지 않는다. 자동 검증 통과가 모든 브라우저와 선택 조합의 무결점을 의미하지는 않는다.
